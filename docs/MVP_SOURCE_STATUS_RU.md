# Фактический статус источников MarketFusion AI

## Навигация при недоступном источнике, 15 ноября 2026 года

В результатах поиска для источника с ошибкой или без подтверждённой обычной цены теперь показывается ссылка на поисковую страницу самой площадки с закодированным запросом. Это бесплатный клиентский переход и способ открыть страницу в Telegram или браузере пользователя; он не является серверным сбором цен и не делает недоступный источник участником автоматического сравнения или мониторинга. Открытие внешнего сайта зависит от его правил и подключения пользователя. Экран отзывов показывает ошибку загрузки вместо бесконечного ожидания; экран сравнения сохраняет индикатор до ответа API и показывает ошибку, если запрос не выполнен.

Дополнительно проверены открытые проекты [avito-watch](https://github.com/Case211/avito-watch) и [marketplace-mcp](https://github.com/YegorMy/marketplace-mcp). Первый прямо требует домашний российский IP для стабильного доступа к Авито/WB и не поддерживает Ozon из-за антибота. Их открытый код не предоставляет нам бесплатный постоянно работающий сетевой маршрут с VPS ко всем десяти площадкам. Исходный коннектор по-прежнему используется; неподтверждённые цены не подменяются данными из поисковых сниппетов или тестового каталога.

Исходная проверка выполнена 14 ноября 2026 года на прежнем VPS через публичный API с действительной Telegram-авторизацией и запросом `ssd`. Это снимок состояния, а не гарантия постоянного доступа: площадки меняют страницы и правила доступа.

При отдельной проверке двух источников Яндекс Маркет и Wildberries вернули 10 карточек, но обычные цены были только у Яндекс Маркета. Поэтому покрытие сравнения цен сейчас составляет **одну площадку**. При повторном одиночном поиске WB браузерное чтение прервалось из-за навигации страницы; доступность поиска нестабильна. Интерфейс явно сообщает, когда у найденных товаров цена не подтверждена.

Дополнительные адаптеры: Детский мир ответил на проверку карточки, категории и списка категорий, но не имеет надёжного текстового поиска в общем сравнении; Cian относится к недвижимости и в сравнение товаров не входит; MPStats требует ключа доступа. Эти адаптеры не следует считать проверенными пользовательскими сценариями MarketFusion.

Проверка отдельных возможностей коннекторов: у WB поиск и отзывы ответили, но повторная диагностика в браузерном режиме завершилась `drift_detected` из-за разметки карточки; у Яндекс Маркета поиск ответил, а тестовая карточка перенаправила запрос (HTTP 302), поэтому её проверка неубедительна. У Ozon поиск, карточка и отзывы не прошли из-за HTTP 403. У Avito поиск блокируется IP, а карточка и продавец без ссылки на конкретный объект не проверялись. У остальных источников успешная карточка и отзывы на этом VPS не подтверждены.

## Новый VPS, 15 ноября 2026 года

Публичный HTTPS API на `48.103.149.93` проверен с подписанной Telegram-авторизацией. По отдельному запросу Яндекс Маркет вернул 5 товаров с 5 обычными ценами. WB по отдельному запросу вернул 5 карточек без обычных цен; доступ нестабилен. Общий запрос ко всем 10 источникам завершился примерно за 45 секунд и дал только 5 цен Яндекс Маркета: WB, Мегамаркет, DNS, Ситилинк и AliExpress завершились тайм-аутом; Ozon, Avito, Taobao и Lamoda сообщили о блокировке или тайм-ауте браузерного перехода. Браузерный CDP при этом доступен, а сервисы после нагрузки остались запущены. Новый IP сам по себе не снял ограничения площадок.

### Повторная раздельная проверка 15 ноября

В общую выдачу добавлена ограниченная проверка одной карточки WB с тем же артикулом: обычная цена принимается только с пометкой `regular`, цена WB Кошелька сохраняется отдельно. До обновления карточка `2124848933` через Chrome показала 3 284 ₽ обычной цены и 3 185 ₽ с Кошельком. После обновления первый поиск WB завершился ошибкой `parser_drift`: браузер открыл оболочку сайта без товарных карточек. Повторный поиск вернул 5 карточек и **1 обычную цену**; совместный запрос WB + Яндекс Маркета вернул 10 карточек и **6 обычных цен** (1 WB, 5 Яндекс Маркета), WB `price_kind=regular`. Это подтверждает рабочий путь цены при доступной выдаче, но не стабильность WB и не идентичность найденных товаров между площадками.

## Браузерный маршрут

Опциональный `docker-compose.browser.yml` запускает Chromium внутри закрытой сети Docker и передаёт его API, боту и worker по CDP. На хосте порт 9222 не публикуется. Браузер помогает только там, где площадка разрешает доступ с IP сервера; он не снимает блокировки IP и не создаёт отсутствующие обычные цены.

Запуск с браузером на VPS: `docker compose -f docker-compose.yml -f docker-compose.browser.yml --profile telegram up -d --build`. Не запускайте второй экземпляр Telegram-бота. После изменения кода перед обновлением базы следует сделать резервную копию данных.

## Что остаётся для полного MVP

- Получить разрешённый доступ к данным для Ozon, Avito и остальных блокирующих площадок; после этого провести реальную проверку поиска, карточек и цен. При текущем условии «без расходов, не обращаться к поставщику» такой доступ не предоставлен.
- Проверить и, где возможно, восстановить обычную цену Wildberries на карточке без подмены ценой WB Кошелька.
- Проверить сравнение конкретного одинакового товара между двумя площадками с подтверждёнными обычными ценами; затем проверить мониторинг и уведомление о реальном изменении цены для каждого рабочего источника.
- Пройти пользовательские сценарии анализа отзывов, поиска по фото, избранного, администрирования и Telegram-уведомлений на работающих источниках. Отдельные работающие проверки этих функций не доказывают весь сценарий.

Наличие адаптера и успешный тест на фикстурах не равны работающему источнику данных. Пока эти пункты открыты, проект нельзя называть полностью готовым MVP для всех заявленных площадок.
