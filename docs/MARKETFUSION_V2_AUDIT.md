## Реальные данные и границы доказательств

Последние живые проверки 15 ноября: Яндекс Маркет — обычные цены; WB — по пять обычных цен для двух запросов; DNS — пять карточек без цен. Остальные семь источников заблокированы, требуют сессии или не возвращают товары. Это исторические результаты предыдущего этапа, не повторная проверка V2. Подробнее `MVP_SOURCE_STATUS_RU.md`.

Локальный baseline: 22 теста прошли, 1 PostgreSQL-тест пропущен без отдельной БД. Docker Desktop при начале аудита не был доступен; запущено его штатное приложение для подготовки тестового окружения. Продуктовые критерии и внешние интеграции этими тестами не доказаны.

## Архитектурное решение

Добавить единый доменный слой V2 поверх работающего коннектора: целые копейки; независимая идентичность товара, варианта, предложения и доставки; exact/probable/similar/rejected; только exact участвует в рейтинге и мониторинге. Неизвестная доставка не равна бесплатной. Асинхронные поисковые задачи с ограниченной конкурентностью, кэшем и приватным доступом владельца. PostgreSQL сохраняет каталог, поиски, watches, наблюдения, события и outbox. Старые неидентифицированные watches помечаются `needs_selection`, данные не удаляются.

Новые UI и Telegram используют этот слой. Старые API, авторизация, избранное, роли, настройки ИИ и анализ отзывов сохраняются как совместимые маршруты; опасный запросный мониторинг перестаёт автоматически сравнивать разные товары.

## Проверка после реализации

Фикстуры отдельно от live: варианты NV3 500GB/1TB/2TB и NV2, русские названия, цена/доставка, изоляция пользователей, ошибки источников, порог и повторные уведомления, миграции и перезапуск, Telegram `/start`/фото, UI. Отчёт должен явно перечислять непроверенные внешние пути. Запрет production deployment сохраняется до отдельного разрешения.
