# V2 implementation contract

Base: `/api/v2`. Same existing Telegram initData header or mf_session cookie; no client-supplied user identity is trusted.

Money: integer minor units, `currency` uppercase ISO; unknown is null. All times ISO UTC.

- `POST /search`: `{query, region?: string, sources?: string[], filters?: {min_price?,max_price?,min_rating?,in_stock?,exact_only?,condition?,delivery_days?}, sort?: relevance|price|total|delivery|rating}` -> `SearchSnapshot` immediately (202). `GET /search/{search_id}` -> incremental snapshot, `DELETE /search/{search_id}` cancels owner's job. At most 5 concurrent jobs per process, one active job per user; 2 source operations across V2 API/bot/worker via PostgreSQL advisory locks (including WB URL resolution).
- Snapshot: `{search_id,query,normalized_query,status: queued|running|complete|cancelled|failed,groups: ProductGroup[],related: ProductGroup[],sources: SourceStatus[],complete:boolean,error?: string,created_at}`. `complete` means all requested sources answered `ok`; it does not prove a match exists or every card has an ordinary price. Individual offer null prices and source diagnostics remain authoritative.
- ProductGroup: `{product:{id,title,brand,model,category,image_url},variant:{id,product_id,attributes,mpn,gtin,condition},offers:MarketplaceOffer[],minimum_price:number|null,minimum_total:number|null,best_price_offer_id:string|null,best_total_offer_id:string|null,sources_count:number,match_status:exact|probable|similar|rejected,reasons:string[]}`.
- Offer: `{id,product_id,variant_id,source,native_id,title,seller,url,image_url,price:number|null,conditional_prices:[{amount,condition}],currency,rating:number|null,in_stock:boolean|null,condition,checked_at,region,delivery:{price:number|null,date_min:string|null,date_max:string|null,region,checked_at:string|null,confidence:unknown|reported|confirmed,conditions},match_status}`. An unknown delivery never produces a confirmed total. Conditional amounts never rank as ordinary prices.
- Source: `{source,status:pending|ok|partial|blocked|timeout|auth_required|rate_limited|parser_drift|unavailable,detail,offers_count,elapsed_ms,checked_at,region,supports_delivery,supports_monitoring}`.
- `GET /products/{id}` -> ProductGroup (owned search/catalog grant). `GET /products/{id}/offers` -> `{offers}`. `GET /products/{id}/history?days=7|30|90|all` -> `{points:[{captured_at,price,source,offer_id}],summary:{min,max,average}}`.
- `GET /recent` -> `{queries:[string],products:ProductGroup[]}` from actual owner's searches.
- `GET /profile` -> `{region}`; `PATCH /profile` `{region}` -> saved profile.
- Existing `/api/favorites` retained. V2 additionally `GET /favorites` -> `{products:ProductGroup[]}`; `POST /favorites` `{product_id}`, `DELETE /favorites/{product_id}`.
- `POST /watches`: `{product_id,offer_id?:string,mode:offer|minimum,region,sources?:string[],threshold?:number,interval_minutes:15|30|60|180|360|720|1440,rules?:{drop_amount?:number,drop_percent?:number,historical_low?:boolean,low_30?:boolean,low_90?:boolean,back_in_stock?:boolean,cheaper_source?:boolean},cooldown_minutes?:number}` -> Watch (201).
- Watch: `{id,product_id,offer_id,mode,title,region,sources,threshold,interval_minutes,active,last_price:number|null,last_checked_at,last_error,rules,cooldown_minutes,state:active|paused|needs_selection}`. `GET /watches` -> `{watches}`; `PATCH /watches/{id}` editable fields; `DELETE /watches/{id}`; `GET /notifications` -> `{notifications:[{id,title,body,created_at,read}]}`.
- Creating a watch requires source offers confirming the requested price region; Yandex reads the actual globalDeliveryPoint region from its source response and may advertise monitoring support. Other current sources report unknown actual region. The selected offer must itself confirm the watch region. Historical favorites remain accessible but their old saved price is not a current quote. `GET /admin/usage` requires admin role and returns provider-reported input/output token totals for the last 30 days, not invented monetary costs.

Backend shared interface: `catalog_v2.service.get_service(db)` returns process singleton SearchService. `await service.search(user_id, SearchRequest(...))` runs complete search for Telegram/worker; `await service.start(user_id, request)` and `await service.snapshot(user_id,id)` serve web tasks. `await service.get_product(user_id,product_id)` returns ProductGroup or raises LookupError. Models in `catalog_v2.models` expose `SearchRequest`, `SearchSnapshot`, `ProductGroup`, `MarketplaceOffer`, `CatalogProduct`, `ProductVariant`, `SourceStatus`, `DeliveryEstimate`.

Monitoring module owns WatchCreate/WatchPatch schemas and `create_watch(db,user_id,payload)`, `list_watches(db,user_id)`, `update_watch(db,user_id,id,payload)`, `delete_watch(db,user_id,id)`, `notifications(db,user_id)`, `history(db,user_id,product_id,days)` and `run_worker(db,token='')`. It uses `get_service(db).search(...)` and `get_product(...)` and exact target matching through `catalog_v2.identity.match_variant(target_variant, candidate_variant)` returning `{status,reasons}`. Legacy watch records are retained, paused and marked needs_selection.


Region comparison excludes a confirmed foreign-city price from the requested-city minimum; unknown regions are displayed as unconfirmed. Source request parameters never prove a price region. Identical MPN alone does not erase new/used/refurbished conflicts; unknown-condition classifieds remain probable rather than lowering confirmed retail groups.

Optional operator-controlled source transport: `MARKETFUSION_SOURCE_AGENT_URL` or `MARKETFUSION_SOURCE_AGENT_SOCKET`, `MARKETFUSION_SOURCE_AGENT_TOKEN`, comma-separated `MARKETFUSION_SOURCE_AGENT_SOURCES`. No client request can select an upstream URL. The agent uses a source whitelist, bearer authentication, 8KB request cap, 20 calls/minute, max 5 queued/2 executing and an 80s total deadline; remote response cap 2MB. See the source-agent guide. A missing route reports unavailable.

Existing `GET /api/reviews?marketplace=yandex|wb|ozon&ext_id=...` remains authenticated. YM/WB use maintained connector readers with shared search-operation gates and native ID validation; YM's requested card route may resolve to a model-family ID. Source failure or a known nonempty pool without usable rated texts returns 503, never a verified empty list. Successful reviews include `scope: unknown|variant_group`; group reviews can describe other variants. The analysis cache includes review content/scope; shared-pool requirements are forced to no_data, with no quote or invented mentions. Telegram retains the scope warning in its final result. Legacy Ozon collection is preserved; ambiguous empty extraction is unavailable. Actual AI/vision generation and Telegram alert delivery remain separate live acceptance checks.
