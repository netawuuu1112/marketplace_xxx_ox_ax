# Приватный поисковый агент V2

Агент выполняет существующие read-only коннекторы через сеть включённого компьютера. На проверенном маршруте он вернул цены Avito, DNS и AliExpress. Это отдельный сетевой путь, а не универсальное снятие блокировок: Ozon, Citilink, Мегамаркет, Lamoda и Taobao остались недоступны. Публичные прокси, обход CAPTCHA и платные сервисы не подключались.

## Проверенный локальный стенд

Из корня ветки после создания `.env.v2-staging` скриптом запуска:

```powershell
docker compose --env-file .env.v2-staging -f docker-compose.v2-staging.yml -f docker-compose.v2-agent.yml --profile agent --profile browser up -d --build
```

API направляет только `avito,dns,aliexpress` на агент; остальные источники используют существующий прямой путь. Web: http://127.0.0.1:8089. Агент слушает loopback 127.0.0.1:8092; Chrome не публикует CDP. Токен `V2_AGENT_TOKEN` генерируется локально и хранится в игнорируемом env. Не публиковать его. В окружении агента нет DATABASE_URL, Telegram-токена или ключей ИИ.

Ограничения: whitelist источников, bearer token, 8KB вход, 20 вызовов/минуту, не более 5 запросов в очереди и 2 выполняющихся, общий срок 80 секунд с ожиданием очереди; клиент принимает до 2MB ответа. Отмена HTTP отменяет работу. Пользовательские URL и перенаправления не используются. Недоступный агент возвращает честный статус unavailable.

## Будущий VPS-маршрут

**Не установлен. Не запускать до отдельного разрешения на production и восстановления VPS.** Ранее проверен только временный диагностический Unix socket, удалённый после проверки. Общий постоянный каталог `/run/marketfusion-agent` не создавался этим выпуском.

После согласованного релиза оператор приватно задаёт один токен на обоих концах. `docker-compose.source-agent.yml` подключает root-only каталог с Unix socket к API/bot/worker и выбирает три источника. На компьютере:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File deployment/scripts/start_private_source_agent.ps1 -ConnectVps
```

Без `-ConnectVps` скрипт запускает только локальные Chrome/agent. С флагом он создаёт на согласованном VPS `/run/marketfusion-agent` с mode700, держит SSH reverse streamlocal к loopback8092 и переподключается после обрыва. Публичный порт не открывается, sshd/GatewayPorts не меняются. Скрипт не устанавливает автозапуск Windows или второй Telegram poller.

Компьютер, Docker, интернет и процесс SSH должны работать постоянно. Закрытие процесса, сон или отключение ноутбука прерывает маршрут. Restart unless-stopped помогает восстановить контейнеры при запуске Docker, но не включает компьютер и Docker Desktop. Поэтому круглосуточная серверная доступность этого пути пока не доказана. Возврат к прямым источникам: убрать agent overlay/config при следующем согласованном запуске, сохранив БД и volumes.
