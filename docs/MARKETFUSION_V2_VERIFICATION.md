Ветка `feature/marketfusion-v2`, [draft PR #9](https://github.com/netawuuu1112/marketplace_xxx_ox_ax/pull/9). Полный MVP по всем десяти площадкам пока не завершён. По §14 ТЗ требуется отдельное разрешение на будущий выпуск.

Точный MPN `SNV3S/1000G` объединён между Яндексом, WB и DNS. Другой MPN `SNV3SM3/1T0` и неподтверждённое состояние объявлений отделены. В выбранном регионе показаны ограничения географии; неизвестная доставка не становится бесплатной. Это не гарантирует одинаковую комплектацию для любой категории или итоговую доставленную стоимость.

Локальный HTTP-сценарий выполнил вход, сохранение профиля Москвы, поиск пяти источников, избранное, создание наблюдения конкретного предложения и одноразовую обработку worker. Измерено **17 301 ₽**, ошибка отсутствовала, точки появились в истории при двух настоящих вызовах worker. Реальное снижение цены и доставка Telegram-уведомления в этом сценарии не происходили. Правила, cooldown, дедупликация и восстановление после сбоев проверены отдельно автоматическими тестами с контролируемыми данными.

Приватный маршрут VPS → временный SSH Unix socket → локальный агент ранее вернул 15 цен Avito и 2 AliExpress; DNS тогда дал карточки без цен. Временный маршрут и каталог удалены после проверки. Постоянный маршрут на VPS не установлен. Локальный агент требует включённых компьютера, Docker и сети; см. [эксплуатационные ограничения](MARKETFUSION_V2_SOURCE_AGENT.md).

Отзывы Яндекса: реальный `/api/reviews` вернул HTTP 200 и 13 текстов из общей карточки. Два выбранных WB nmId вернули basket 404: API корректно сообщает 503; живое чтение WB-отзывов остаётся открытым. Новый reader не подменяет сбой пустыми отзывами, не выдумывает оценки и не подтверждает выбранную комплектацию по общему пулу. Проверка не включала платный анализ.

## Локальные проверки

- 117 Python-тестов, включая настоящую изолированную PostgreSQL, HTTP, владение данными, миграции, reconnect, worker и новые регрессии. Итоговый запуск и статус CI записываются в PR.
- 6 браузерных сценариев с **явными API-фикстурами**: промежуточные результаты, отмена, выбранный вариант, неизвестная доставка, фактический регион, чужой город и вход. Они не доказывают доступ к площадкам.
- TypeScript/Vite и Docker-образы API/Web/агента собраны. Отдельный живой smoke без перехвата API проверяет вход/HttpOnly, четыре вкладки, Origin PATCH через Nginx, защищённое управление, demo=false, отсутствие JS-ошибок и переполнения на ширине 390px.
- Backup/restore **непустой локальной** БД: сверены полные JSONB-отпечатки десяти таблиц, включая товары, варианты, предложения, избранное, измерения и watches. Это не восстановление production. Новая попытка получить production dump остановилась на недоступном SSH до чтения SQL/env.
- Ранее после поиска измерено около 681 MiB у API/agent/Chrome/PG/Web вместе. Это не нагрузочный тест полного bot/worker-стека на VPS с 1GB RAM.
- AITunnel `/models` доступен, vision-модель присутствует; исправлен пропущенный маршрут vision для этого провайдера. Платная генерация не запускалась, поэтому распознавание фото и AI-анализ end to end не приняты.

## Что остаётся до полного MVP

Разрешённый устойчивый доступ к пяти заблокированным площадкам; регион/доставка и слежение остальных источников; живые WB-отзывы; фактическая фото/AI-генерация; доставка Telegram-уведомления при настоящем событии; восстановление production-копии и нагрузочная приёмка после возвращения серверов. Никакие расходы или обращения поставщикам не выполнялись. Для исходников и лицензий см. SOURCES.md; Grex/PriceWatch без лицензий не копировались.
