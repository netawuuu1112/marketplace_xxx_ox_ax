# Данные Ozon и Wildberries для MarketFusion

Состояние на 12 ноября 2026 года: MarketFusion работает на VPS, но запросы к Ozon и Wildberries с его IP блокируются. Пользователь выбрал источник данных с разрешением на использование. Доступ к такому источнику и договор пока отсутствуют. Не подменять живые предложения демо-каталогом.

## Кандидаты

1. [MPSTATS Data](https://mpstats.io/landing/custom-research?from=mpstats.api_docs.banner) заявляет сбор данных Ozon и Wildberries, передачу через API и подбор решения под клиента. [Обычный API MPSTATS](https://mpstats.io/integrations/docs/description/) работает с персональным токеном и имеет лимиты. Публичная страница не подтверждает право отображать цены и карточки в пользовательском приложении; это требуется письменно согласовать. Тариф обычного API не следует считать тарифом MPSTATS Data.
2. [Ozon Statistics API](https://dev.ozon.ru/news/256-Novyi-API-dlia-polucheniia-dannykh-Statistics-API/) предлагает коммерческий доступ независимым аналитическим сервисам к характеристикам и ценам Ozon. Нужен отдельный договор; Wildberries он не покрывает.

Seller API отдельной площадки не решает задачу поиска по общему каталогу чужих продавцов. Текущие браузерные и HTTP-адаптеры остаются резервным техническим вариантом, но не обеспечивают стабильную выдачу с этого VPS и не заменяют права на использование данных.

## Что нужно подтвердить до оплаты и интеграции

- Договор разрешает показывать пользователям публичного Telegram-бота, Mini App и веб-приложения название, цену, изображение, рейтинг и ссылку на карточку товаров Ozon и Wildberries; сравнивать предложения и отправлять уведомления об изменении цены. Уточнить право на хранение истории цен и срок хранения, обязательную атрибуцию и правила удаления данных.
- API позволяет искать товары по произвольному текстовому запросу пользователя и получать карточку по ID/ссылке, а не только выгружать заранее согласованный список SKU для внутренней аналитики.
- Для каждого предложения доступны: площадка, ID товара, название, цена и валюта, прямая ссылка, время измерения, регион цены, доступность. Отдельно согласовать изображения, скидки, рейтинг, количество отзывов, варианты товара и продавца.
- Поставщик указывает задержку обновления данных, охват каталога, допустимую нагрузку, цену за месяц и/или запрос, минимальный платёж, лимиты, условия превышения, пробный доступ, SLA и порядок прекращения доступа.
- Предоставляется документация конкретных методов и обезличенный пример JSON для текстового поиска и чтения карточки по обеим площадкам. Перед покупкой провести тест по запросам `ssd`, `iphone 16`, `кофемашина` и нескольким URL, сравнить ссылку, регион, цену и время обновления с карточкой площадки.

## Черновик обращения к MPSTATS Data

> Тема: Данные Ozon и Wildberries для пользовательского сервиса сравнения цен
>
> Здравствуйте! Разрабатываем MarketFusion AI — Telegram-бот, Mini App и веб-приложение для поиска и сравнения товаров Ozon, Wildberries и Яндекс Маркета: https://marketfusionai.kosmo-connect.ru/. Нам нужен лицензированный API для поиска по произвольному запросу пользователя и получения карточки по ID/URL. Результаты (название, актуальная цена, изображение, рейтинг, ссылка, время обновления) показываются пользователям; также планируются сравнение и уведомления об изменении цены.
>
> Подтвердите, пожалуйста: разрешает ли ваш договор такой публичный показ и хранение истории цен; покрывает ли API обе площадки и поиск по общему каталогу; какова частота обновления и регион цен; какие лимиты, минимальная стоимость и условия пилота? Пришлите документацию подходящих методов, пример JSON и условия использования изображений. Возможна ли работа с физическим лицом, или нужен договор с ИП/ООО?

Черновик не отправлен. Перед отправкой пользователь должен указать бюджет и явно поручить связаться с поставщиком. Ключи и платёжные данные в переписку или репозиторий не добавлять.

## Подключение после получения доступа

1. Сверить договор, методы и пример ответа с требованиями выше. Если публичный показ не разрешён либо нет произвольного поиска, выбрать другой договор/источник.
2. Реализовать отдельные адаптеры Ozon и Wildberries через лицензированный API с существующим контрактом `backend/adapters`. Секреты хранить вне Git. Обрабатывать 401, 429/`Retry-After`, таймауты, пустой ответ, регион и устаревшую цену; не маркировать старые данные как живые.
3. Прогнать контрактные тесты по предоставленным примерам и живые проверки через HTTPS для бота, Mini App, сравнения, избранного и мониторинга. После проверок обновить README и статус источников в интерфейсе.

Лицензии Grex и PriceWatch касаются **их исходного кода** и не дают права переносить его в MarketFusion. Нужные возможности разрабатываются независимо. Это отдельный вопрос от договора на товарные данные.
